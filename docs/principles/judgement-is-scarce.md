# Judgement is the scarce input

**The rule:** automate production freely. Never automate the decision about what is worth saying.

## Why

AI collapsed the cost of producing words. It did not collapse the cost of deciding which words are worth producing — recognising which signal matters, knowing which argument the evidence will actually support, holding a position when it is inconvenient.

As production approaches free, its value approaches zero, and the scarce input becomes the judgement upstream of it. That is also the defensible part: production capability can be bought by anyone, while judgement is accumulated and specific to an organisation.

This is not an argument against using AI. It is an argument about where to point it.

## The dividing line

| Automate | Keep human |
| --- | --- |
| Drafting, formatting, restructuring | Deciding what is worth saying |
| Summarising and extracting | Deciding which signal matters |
| Retrieval and cross-referencing | Deciding what the evidence supports |
| Variant production for channels | Deciding the position |
| Consistency and mechanical checks | Deciding when to change the position |

The left column scales with tooling. The right column scales with accumulated understanding — which is why the rest of this system exists to build it.

## What it rules out

- Fully autonomous publishing without a judgement checkpoint
- Treating an AI draft's confidence as evidence
- Volume targets that force output ahead of a position
- Outsourcing the framing of a problem to a model that has not seen the evidence

## Test

Ask of any workflow: *at which step does a human decide what is true and what matters?* If there is no such step, the workflow automates judgement, not production.
